# We could reduce our binary operators even further than we did here. Which other instructions can you eliminate, and how would the compiler cope with their absence?

Subtraction and unary negation duplicate each other’s functionality. Subtracting one value from another is equivalent to negating the second value and then adding it, and negation itself can be expressed by subtracting a value from zero. The same idea applies to comparison operators. Instead of having separate instructions for “less than,” “greater than,” “equal,” and so on, the VM could define a single three‑way comparison instruction that returns whether one value is less than, equal to, or greater than another. The compiler would then translate all comparison expressions into tests against that single result. Reducing the instruction set simplifies the VM and makes it easier to maintain, at the cost of slightly more work in the compiler, which must generate multi‑step sequences for operations that no longer have dedicated opcodes.
